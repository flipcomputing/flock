Rotate the camera around a single object. View object gizmo Step 1: View an object The view object gizmo allows you to center your view on any object in your scene. This is really useful when you are combining objects. Or want to see your scene from different angles. Click the view object gizmo. If you already have an object selected the view object gizmo will attach to it. Or, you can click on any object to attach the view object gizmo. The object you are viewing always has a purple box around it. Step 2: Rotate around the object Drag to rotate around the object. Tip: You might move so that you are viewing the object from under the ground. Just keep rotating up to get back above ground. Step 3: Rotate with movement controls Use the [movement controls] on the canvas or WASD to rotate the view. Step 4: Zoom in and out Use the left action buttons to zoom in and out, or 1/R and 3/space on a keyboard. On touchscreen devices, you can use two fingers to zoom. Zoom in for detailed work. Zoom out to see more of your scene. Step 5: Move the view gizmo to another object Click on another object in the scene to move the view gizmo. Use this approach to move around the scene. Step 6: Use other gizmos You can use other gizmos while the view gizmo is active. Try using the [color gizmo] or [position gizmo] Click a gizmo button again to stop using it. When only the view gizmo is selected you can move it to another object. Step 7: Stop using the view object gizmo When the view object gizmo is active you can't move round with the fly camera or by moving the player. Click on the view object gizmo again to stop using it. You will return to using the camera you were using. Tip: Use the purple box to line up your view. You might want to view an object from the front or the top.
