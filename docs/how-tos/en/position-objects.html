Position an object on the 3D canvas. Choose the position gizmo

Click Position in the gizmo bar. If an object is already selected, the position gizmo attaches to it. Otherwise, click the object you want to move on the canvas.

Drag an arrow

Drag one of the arrows and let go when the object is in the right place. Each arrow moves along one axis:

  • The blue X arrow moves it side to side.
  • The green Y arrow moves it up and down.
  • The orange Z arrow moves it forward and back.
 Use canvas controls

Use the on-screen gizmo controls: tap the X, Y, or Z button for the axis you want to move along, then use the - and + buttons to position the object.

Show or hide gizmo controls from Menu > Tools > Gizmo controls.

Switch objects

Click on another object to move the position gizmo to it.

Put the gizmo away

When you have finished, click off the canvas or click the Position button again.
