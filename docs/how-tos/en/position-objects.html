Move an object exactly where you want it. Choose the position gizmo

Click Position in the gizmo menu. If an object is already selected, the gizmo attaches to it — otherwise, click the object you want to move on the canvas.

Drag an arrow

Drag one of the arrows and let go when the object is in the right place. Each arrow moves along one axis:

  • The blue X arrow moves it side to side.
  • The green Y arrow moves it up and down.
  • The orange Z arrow moves it forward and back.

Move slowly at first — small movements are easier to control.

 Or set its position in code

You can also set its position with the block's X, Y, and Z values. They use the same colors as the arrows, so match the value to the arrow you want.

Pick a position from the canvas

You can also go the other way: click the pin icon on the block, then click a surface on the canvas. The block's X, Y, and Z values update and the object moves to the new position.

Switch objects

Click on another object to move the position gizmo to it.

Use canvas controls

You can also use the on-screen controls: tap the X, Y, or Z button for the axis you want to move along, then use the - and + buttons to position the object.

Put the gizmo away

When you have finished, click off the canvas or click the Position button again.

Moved it too far? Undo, then move it again slowly.
