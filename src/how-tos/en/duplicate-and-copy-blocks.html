Make copies of blocks so you don't have to build the same code twice. Duplicate a block

Select a block and click Duplicate in its block menu. A copy appears next to the original, ready for you to drag wherever you want it. With the keyboard, press D on a focused block.

Copy and paste

Select a block and click Copy in its block menu, or press Ctrl+C. Then click Paste, or press Ctrl+V. The copy is added straight after the selected block.

Make several copies in a row

Keep pasting to make a stack of connected copies — each new copy is added after the last one. Copy an add star block and paste it twice to get three stars:

Paste somewhere else

After copying, move to another place in your code and select a block there, with the mouse or the keyboard. When you paste, the copy is added after that block.

Move the new objects

If you copy a block that adds an object, the copy adds its object in the same place as the original, so they sit on top of each other. Move each one with the Position gizmo, or click the position pin on the copied block and then click where you want the object on the canvas.
