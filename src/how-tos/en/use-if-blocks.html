Run blocks if something is true

Add an if block from Condition. Put a condition in its slot and blocks inside it. The blocks inside run only when the condition is true.

Each press checks count and then adds 1 to it. count is only 0 on the first press, so the message shows once.

Change if to else if or else

Click the word if on the block and choose else if or else. Connect these blocks under an if block to make one choice:

  • else if checks its own condition when the blocks above it did not run.
  • else has no condition. It runs when none of the blocks above it ran.

Only one part of the choice runs, and the blocks are checked from the top. That is why count = 0 comes first: 0 is also less than 10, so if count < 10 came first, First press! would never show.

Connect them in order

The blocks only work in this order:

  • if comes first.
  • else if comes after if or another else if. You can have as many as you need.
  • else comes last. You can only have one.

A block in the wrong place is greyed out and does not run. Move it to the right place, or change it to a different choice, and it works again.
