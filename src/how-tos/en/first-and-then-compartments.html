Set up an object before it appears with its first compartment, and make it do things once it is in the scene with its then compartment. Open the compartments

Click the + button at the end of an add block's first row. This opens the rotation row, which also has size on some blocks. Click the + button at the end of the rotation row to open the first compartment. Then click the + button under the first compartment to open the then compartment.

Click − to close a compartment. The blocks inside it are kept and still run.

Alternative: Move to the + or − button on the block with the keyboard and press Enter.

The first compartment

The first compartment is what the object does first, before it appears in the scene. The object stays hidden, and doesn't bump into anything, until these blocks have finished, so it appears already set up.

Use it to get the object ready: add physics, change its color, resize or rotate it, switch it to an animation, or give it a push to launch it.

The then compartment

The then compartment runs once the object is in the scene. Use it for things that happen over time: waiting, moving, playing an animation, repeating forever, or removing the object later.

The next block doesn't wait

Neither compartment stops the next block from running. The block under the add block starts straight away, while the first and then compartments carry on at the same time.

If the next block does something to the object, it waits until the object has been created.

A repeat 10 times loop around an add sphere block. Its first compartment adds physics and applies a force; its then compartment waits 3 seconds and disposes the sphere. To make something happen after the then compartment has finished, put it at the end of the then compartment.
