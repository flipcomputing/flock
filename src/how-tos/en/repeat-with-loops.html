Repeat a number of times

The repeat block in Control runs the blocks inside it the number of times you choose.

Repeat while or until

repeat while keeps going as long as something is true. Change it to repeat until to keep going until something becomes true.

Count

for each counts from one number to another. Use count inside it to get the number it has reached.

Go through a list

for each item in list runs once for each item in a list.

Repeat forever

The forever block in Events repeats until the project stops. It finishes the blocks inside before it starts again.

Stop early

Put break out of loop from Control inside a loop to stop it.
