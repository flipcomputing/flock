Select an object so you can work with it. Choose the select gizmo

Click Select in the gizmo bar, then click on an object on the canvas.

Alternative: Use the arrow keys to move the cursor over an object then press Enter.

 See what selecting does

A box outline appears around the selected object. Its current position appears on the canvas. The code block for the object is highlighted on the workspace.

Switch object

When the select gizmo is active, click another object to select it instead. The box outline moves to the new object, and its code block is highlighted.

Finish selecting

To stop selecting, click off the canvas or click the Select button again.
