Make a variable

A variable is a name that holds a value. Open Variables and drag out a set block. Use the dropdown on the block to give the variable a name.

Text

Set the variable to some text, then use it wherever text goes.

 A number

Set it to a number at the start. change by adds to it. This counts clicks on the star.

An object

The name on an add block, such as star1, is a variable that holds the object. Set another variable to it, and blocks that use that variable act on the object.
