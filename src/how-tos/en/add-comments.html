Add notes to your code so you and other people can understand it. Comment blocks

A comment block is a line of notes that fits in a stack, right next to the code it explains. It doesn't do anything when your code runs.

Drag one in from Text, click its text and type your note. With the keyboard, press Ctrl+., type // and press Enter to add one.

Workspace comments

A workspace comment is a sticky note that sits anywhere in the code area, on its own rather than in a stack. Use it for bigger notes, like instructions for your project.

Press Play, then click the star to make it spin.

Right-click an empty part of the code area — on a touchscreen, tap and hold — and choose Add Comment, then click inside the note and type. Drag the note's top bar to move it.

With the keyboard, press W in the code area to select the workspace itself, then press Ctrl+Enter and choose Add Comment. Press Enter on the note to start typing, and Esc when you've finished. To move the note, press M, use the arrow keys to position it and press Enter.
