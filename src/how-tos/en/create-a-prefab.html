When to use a prefab

A prefab is a template for an object. Use one when you want lots of similar objects that can be slightly different, such as shelves of different widths and colours. You build the object once, then add as many objects as you need.

Build the template

Drag the add prefab block from Functions into the code area and give it a name. Put the blocks that build the object inside it. Nothing appears in the scene until you add the prefab.

Press the plus button to add an input, such as width, and use it inside the prefab. Use the material input to colour the parts. To remove an input, press its minus button. To get the material back, right-click the prefab and choose Add material input. With the keyboard, press Ctrl+Enter on the prefab block to open the same menu.

Add objects from it

Functions has an add block for each prefab. Each add block makes one object, with its own position, rotation and input values.

If you change the blocks inside the prefab, every object made from it changes too.
