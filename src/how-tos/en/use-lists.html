Make a list

A list holds several values in order. Open Lists and set a variable to a list block. Press on the block to add an item, or to remove one.

Get an item

in list get gets an item by its place in the list, or a random one.

Use every item

for each item in list from Control runs once for each item.

Change a list

Use add to to put an item on the end, and delete from to take one out.
