Add a when block

Add a when block from Events, choose a control, and put blocks inside. The blocks run each time the player presses that control.

Choose released instead of pressed to run the blocks when the player lets go.

The controls

There are four directions and four buttons to choose from:

  • forward, backward, left and right
  • button 1, button 2, button 3 and button 4

Each one works with the keyboard, the on-screen buttons and a games controller, so your project works on any device. Player Controls shows which key or button is which.
