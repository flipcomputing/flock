Rotate the camera around a single object. View an object

The view object gizmo centers your view on any object in your scene. This is really useful when you are combining objects, or want to see your scene from different angles.

Click View in the gizmo bar. If you already have an object selected, the view object gizmo attaches to it. Otherwise, click any object on the canvas to attach it.

The object you are viewing always has a purple box around it.

Rotate around the object

Drag to rotate around the object.

You might end up viewing the object from under the ground. Just keep rotating up to get back above ground. Rotate with movement controls

Use the on-screen movement controls, or W A S D on a keyboard, to rotate the view.

Zoom in and out

Use the left action buttons to zoom in and out, or 1/R and 3/Space on a keyboard. On a touchscreen, use two fingers to zoom.

Zoom in for detailed work. Zoom out to see more of your scene.

Switch objects

Click on another object in the scene to move the view gizmo to it. Use this to move around the scene.

Use other gizmos

You can use other gizmos while the view gizmo is active. Try Color or Position.

Click a gizmo button again to stop using it. When only the view gizmo is selected, you can move it to another object.

Put the gizmo away

While the view object gizmo is active, you can't move around with the fly camera or by moving the player.

Click the View button again to stop using it. You will return to the camera you were using before.

Use the purple box to line up your view — for example, to view an object from the front or the top.
