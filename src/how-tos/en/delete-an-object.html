Remove an object you don't want any more. Select an object

Click Select and then click the object you want to delete on the canvas.

Start deleting

Click Delete in the gizmo bar. If you have an object selected, it will be deleted.

Delete more objects

With the delete gizmo selected, click on objects to delete them.

Stop deleting

Click away from the canvas or click the Delete button again to stop deleting.

You can also press Delete or Backspace to delete the selected object. Press Ctrl+X to cut an object, then select another object and press Ctrl+V to paste it at the same location.
