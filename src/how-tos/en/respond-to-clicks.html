Make something happen when an object is clicked. Add a when clicked block

Add a when clicked block from Events, choose your object, and put blocks inside.

With the keyboard: go close to the object and press E or 2 when the interact indicator appears.

Clicking again

Clicking the same object again does nothing until the blocks inside have finished. await makes the glide wait until it ends, so the star can't be clicked again while it moves.

Many objects

One when clicked block works for every object an add block makes in a loop, or every object with a tag. Inside it, the name means the object that was clicked.
