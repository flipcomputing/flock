Save blocks to a file so you can share them or use them in another project. Export a snippet

Right-click a block — on a touchscreen, tap and hold — and choose Export block as snippet. This saves the block, and all the blocks below it, as a snippet file ending in .fsnip. With the keyboard, press Ctrl+Enter on a focused block to open the same menu.

Export a picture

Choose Export as PNG from the same menu to save a picture of the blocks. The picture contains the code too, so anyone you share it with can import it and get the real blocks back — not just look at them.

Import code

Right-click an empty part of the code area and choose Import snippet, then pick a .fsnip file or a PNG picture exported from Flock XR. You can also drag the file straight onto Flock XR. With the keyboard, press Ctrl+Enter on the code area and choose Import snippet.

To save your whole project rather than a few blocks, press Ctrl+S.
