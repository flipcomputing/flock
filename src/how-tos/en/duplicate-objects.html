Copy an object you already like. Choose the duplicate gizmo

Click Duplicate in the gizmo menu. If an object is already selected, the gizmo attaches to it — otherwise, click the object you want to copy on the canvas.

Place the copy

Click a surface on the canvas to place the copy there. The code block for the copy appears with your blocks, so your scene and your code stay in step. Keep clicking to place more copies — each new copy becomes the one that gets copied next.

Put the gizmo away

When you have finished, click off the canvas or click the Duplicate button again.

Placed it in the wrong spot? Undo, then place it again — or nudge it into place with the Position objects how-to.
