Change the color of an object. Choose the color picker gizmo

Click the Color picker in the gizmo bar. The color picker will appear.

Select a color

Click on a color swatch. Then click on an object on the canvas. The object changes to the selected color. Click on more objects if you want them to be the same color.

Use a color palette

Click the color palette drop down menu and choose a palette to get a new set of colors.

Choose a random color

Click the random color button to get a random color. Keep clicking until you find a color you like.

Use the color wheel and sliders

Click the color wheel to select a color. Use the brightness slider to change how light or dark the color is. Use the color slider to find a different color of the same brightness.

Pick a color

Click the color selector button. The color selector will appear. Move around to find the color you want to pick and then click to select it. Note: The color selector is only available on browsers and devices that support it.

Change a color in a code block

Choose a color and then click on a color in a code block.

Close the color picker

Click away from the canvas and color picker to close it. You can also click the Color picker button again to close it.

Some objects have multiple parts with different colors. Click on a part to change its color.
