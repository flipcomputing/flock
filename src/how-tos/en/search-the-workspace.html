Find blocks that are already somewhere in your code. Search

Click Search below the code area and type what you're looking for, like a block's name or a word you typed into it. The search box shows how many blocks match, and the code area jumps to the first one. With the keyboard, press Ctrl+F in the code area.

Go through the results

Click the down and up arrows in the search box to go to the next or previous match. With the keyboard, press Enter for the next match and Shift+Enter for the previous one.

Go to a block

Click a matching block to work on it. With the keyboard, press Esc to leave the search box and go to the selected match. Click the × to close the search.
